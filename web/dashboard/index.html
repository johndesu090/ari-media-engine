Embedding security

Global allowed domains (one per line, “*.” matches subdomains)

Enforced via Content-Security-Policy: frame-ancestors plus server-side origin checks on /player.html.

Playback tokens (HLS / DASH)

Token TTL (seconds)

Tokens are HMAC-signed and embedded in the URL path (/hls/<token>/<streamId>/…) so playlists and segments stay authorized.

Transcoding

When off, streams are remuxed with no re-encoding so playback follows your OBS/encoder settings exactly (lowest CPU). Changes apply to new publishes. Active sessions: 0.

Peer-to-peer delivery

Viewers share segments over WebRTC data channels via the tracker at /p2p/ws, falling back to the origin. Connected peers: 0.

Quick start

Publish from a browser or OBS, then embed the player anywhere on an allow-listed domain.
